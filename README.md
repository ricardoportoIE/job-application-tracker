# Job Application Tracker

A production-oriented full-stack application for tracking job applications,
companies, interviews, and hiring pipelines.

## Status

🚧 In development

## Purpose

Job searching often involves tracking vacancies, companies, recruiters,
interviews, deadlines, notes, and application statuses across multiple tools.

Job Application Tracker centralizes this information into a single application
and provides visibility into the user's hiring pipeline.

## Planned Features

- User authentication
- Job application management
- Company management
- Interview tracking
- Application status history
- Search, filtering, sorting, and pagination
- Dashboard and application analytics
- Secure user-specific data access
